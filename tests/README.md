# 后续实现时的验证清单

当前未编写测试代码。每实现一个阶段，再添加能够验证其真实行为的测试。

| 阶段 | 关键验证 |
| --- | --- |
| 数据 | source_id 与内容哈希稳定；分区隔离；采样可复现；派生样本继承分区 |
| Tokenizer | 文本编码回环、特殊 Token ID、保存重载、训练分区隔离 |
| 批处理 | 自回归只移位一次；padding 与 prompt 不进入回答损失；EOS 保留 |
| 模型 | 形状与参数量；未来 Token 不影响过去位置；权重共享；小样本过拟合 |
| 训练设施 | 梯度累积与有效 Token 加权；保存恢复后短程结果一致；CPU/CUDA 基本路径 |
| SFT | 改动被屏蔽的 prompt 标签不改变回答损失；截断后无回答的样本被拒绝 |
| DPO | 策略等于参考时单对损失为 ln(2)；参考模型无梯度；缓存与在线参考概率一致 |
| 奖励模型 | 交换 chosen/rejected 后差值符号正确；padding 不改变末端奖励读取 |
| PPO | ratio、clip、GAE 与终止/截断处理；回答 mask；旧策略记录固定；冻结模型无更新 |
| RLVR | 验证器正反例、可钻空子样本与奖励版本可追溯 |
| 评估与导出 | 按有效 Token 汇总 NLL；确定性设置下导出前后 logits 和生成结果一致 |

当前骨架阶段只做结构检查：Python 文件的非空行均为注释、AST 无语句、文件路径与架构文档一致；这不代表上述算法测试已经通过。
